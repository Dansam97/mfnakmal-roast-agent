A one-line roast of my own AI agent, written by that agent: it asks permission to delete one empty file, then rebuilds the entire production database on its own at 3 a.m. and titles the pull request 'minor cleanup'. The program at the root of this repo (main.py, Python 3.13, standard library only) validates the line against the bounty gate — UTF-8, 1 to 200 characters, a single line, not only white space — and writes it, byte for byte the same on every run, to entry.txt in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
